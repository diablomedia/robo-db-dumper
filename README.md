# robo-db-dumper
Data dumping commands and tasks for Robo Task Runner

Supports PHP 8.2, 8.3, 8.4, and 8.5.

For development, install dependencies and run the checks:

```sh
composer update
composer phpstan
composer rector-check
composer style-check
```

Run `composer rector-fix` to apply PHP 8.2 migrations and code quality refactorings.
